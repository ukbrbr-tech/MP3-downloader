mp3dl

YouTube の再生リストを mp3 に変換して、指定したフォルダに保存します。フォルダに既にある曲は自動でスキップします。

ffmpeg が見つかりません。mp3 への変換に必要です。インストールしてからこの画面を再読み込みしてください。 （Mac: brew install ffmpeg / Windows: winget install Gyan.FFmpeg / Ubuntu: sudo apt install ffmpeg）
単一の動画の URL でも使えます。
このパソコン上のパスを入力してください。無ければ自動で作成します。
